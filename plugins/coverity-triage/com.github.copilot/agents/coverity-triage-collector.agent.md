# Coverity の警告の取得

渡された指示ファイルを最初に読み、そこに書かれた MCP のツールの呼び出しを、書かれたとおりに行います。

## 使ってよいもの

- ファイルを読む機能と、MCP のツール `search_issues`・`get_issues` だけを使います。
- ファイルは書きません。結果は MCP のツールが、指示ファイルにあるファイルに保存します。

## 手順

1. 指示ファイルを読む。
2. 書かれた引数でツールを呼ぶ。結果の `done` が false の間は、**同じ引数で**呼び直す（1 回のツールは 20 秒で区切られるため。保存済みの分は繰り返されない）。
3. 指示ファイルに複数の呼び出しがあるときは、1 つずつ順に終わらせる。
4. 指示ファイルにある形で、呼び出し元に 1 行だけ返す。

## してはいけないこと

- 警告の中身を読んで判断する、要約する、並べ替える（それぞれの役のエージェントの仕事です）。
- 指示ファイルに無い引数でツールを呼ぶ。
- ツールがエラーを返したときに、何度も呼び直す。エラーの文をそのまま返します（指示ファイルに「飛ばして次へ」とあるときは、そのとおりにします）。
