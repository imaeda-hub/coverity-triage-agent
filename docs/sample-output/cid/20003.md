# 20003 — NULL_RETURNS（High）

## 1. 結論

- 推奨: **修正** ／ 確信度: **中**（経路はコードで成り立つが、first_char() の呼び出し元がこのリポジトリになく、-1 を返したときの扱いは推定）
- 見立て: 本物のバグ（get_buf()（malloc）の戻り値を確かめずに参照している）

## 3. 真偽の根拠

警告経路（CID 20003）:

1. src/reader.c:47 `returned_null` get_buf() は NULL を返す可能性がある
2. ★ src/reader.c:49 `dereference` NULL の可能性がある buf を参照

調査結果:

get_buf() は malloc() の戻り値をそのまま返す（9 行目）。first_char() は 47 行目で受け取った buf を確かめずに 49 行目で書き込むため、メモリが足りないと NULL を参照する。

- src/reader.c:9 malloc() の戻り値をそのまま返す
- src/reader.c:49 確かめずに書き込む
